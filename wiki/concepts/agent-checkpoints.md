# AI Agent 的人類檢查點

## 背景
「代理（agent）」是 LLM 自己決定流程與工具的系統；「工作流程」則走預先寫好的路徑。 [S7]
Agent 能力越強，越需要設計人在哪裡介入。（綜合）

## 三個控制手段
1. **開頭對齊**：Agent 從人的指令或討論開始，任務清楚後才自主執行。 [S7]
2. **檢查點**：在關鍵步驟或卡住時暫停，等人回饋。 [S7]
3. **停止條件**：例如最大迭代次數，避免無限循環。 [S7]

另外每一步都要從環境拿到真實回饋（工具結果、程式執行結果）來判斷進度。 [S7]

## 建議
先用最簡單的解法；不是所有任務都需要 Agent。 [S7]
